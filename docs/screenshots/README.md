# Демонстрационные экраны

Снимки публичного интерфейса версии1.3.5,20ноября2026. Вымышленные имена, стандартные аватары и синтетические результаты; фотографии и данные действующих семей не использовались.

1. [Телефон](phone-parent.jpg): родительская проверка отметок, очки, минуты, копилка и родительские решения.
2. [Телевизор](tv-calendar.jpg): общий календарь, столбики, отдельные цели и недельный прогресс.
3. [Машина](car-profile.jpg): профиль ребёнка, дневные задания и награды в сенсорном режиме.

Это скриншоты работающего кода в браузере с соответствующими размерами и режимами. Они показывают раскладки приложения; это не фотографии физических устройств. Локальный демонстрационный сервер не связан с рабочими семьями.
