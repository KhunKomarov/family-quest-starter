# Нейросети: настройка семьи от начала до конца

Основной маршрут публичной версии 1.3.5. Сначала выберите ситуацию:

1. Есть личное приглашение — сервер готов, пройдите этапы 1–8.
2. Семья создана — проверьте выполненные этапы и продолжайте с нужного экрана.
3. Есть только GitHub и сервера нет — выполните [свою установку](install.md). Данные и доступы задаются там, чужое приглашение не требуется. Затем продолжайте с этапа 3 ниже.
4. Требуется обновление — следуйте [порядку сохранения семьи](updating.md).

Возможности описаны в [README](../README.md), начисления — в [правилах](rules.md). Особенности частной установки не являются обещанием публичного шаблона.

Выполняйте этапы по порядку. Давайте человеку одно небольшое действие за раз; доступные инструменты используйте сами. При регистрации пользователь выбирает фото и вводит новые личные коды, при подключении ТВ — помогает пультом. Не требуйте изучать технические файлы.

| Этап | Результат |
| --- | --- |
| 1. Подготовка | Проверены ТВ, компьютер и возможности помощника |
| 2. Регистрация | Создана семья |
| 3. Телефоны | Родители открывают кабинет |
| 4. Настройки экрана | Получен семейный пакет |
| 5. Сборка | Подготовлен APK |
| 6. Телевизор | APK установлен и запущен |
| 7. Проверка | Отметки и изменения синхронизируются |
| 8. Обучение | Родители умеют добавлять дела и цели |

Уже пройденный этап проверяйте, затем продолжайте со следующего. Ошибки разбирайте по [таблице симптомов](troubleshooting.md), не начинайте установку заново без причины.

## 1. Подготовьте подключение

Сначала спросите модель и систему телевизора, какой компьютер доступен и есть ли приглашение или кабинет. Если нет приглашения и сервера, выберите с пользователем собственное размещение по инструкции установки; платные расходы согласует пользователь. Остальные сведения собирайте при настройке. Уже зарегистрированную семью не регистрируйте заново.

Можно начать так:

> Помогу настроить трекер: у родителей будет кабинет на телефоне, у детей — приложение на телевизоре. Сервер по вашему приглашению уже готов. Сначала назовите модель ТВ и какой компьютер есть рядом: Windows, Mac или Linux. Если модель неизвестна, покажу, где её посмотреть.

Нужен Android 9 или новее с возможностью установки APK; для телевизора подходят Android TV / Google TV и совместимые Android-приставки. Название Smart TV само по себе не подтверждает совместимость. Tizen и webOS не запускают этот APK; для такого экрана предложите совместимую внешнюю Android-приставку либо другой поддерживаемый экран. Не покупайте устройство от имени семьи.

Попросите открыть «Настройки → Система / Настройки устройства → Об устройстве» и назвать модель и версию системы. Точный путь зависит от производителя. Для незнакомой модели проверьте официальную инструкцию, а не угадывайте сочетания клавиш. Сфотографировать экран с моделью можно вместо переписывания текста.

Объясните: компьютер и телевизор должны видеть друг друга в домашней сети для установки через ADB. Сам трекер синхронизируется с сервером через интернет; после установки компьютер можно выключить. Родительский телефон и телевизор могут пользоваться разными сетями.

| Доступ помощника | Что делать самостоятельно | Что потребуется от человека |
| --- | --- | --- |
| Браузер и терминал на компьютере семьи | Пройти разрешённые шаги в кабинете, скачать настройки, подготовить инструменты, собрать APK, установить на подключённый ТВ | Новые коды родителей, фото по желанию, действия пультом и подтверждение подключения |
| Браузер без терминала | Работать в кабинете, добавлять дела и цели, скачать пакет | Для сборки понадобится помощник с терминалом или выполнение предложенных команд на компьютере |
| Терминал в облаке, вне домашней сети | Подготовить APK в доступной приватной среде и передать готовый файл семье | Установка файла на ТВ разрешённым способом; локальный ADB из облака не доступен автоматически |
| Только обычный текстовый чат | Объяснять шаги и готовить команды под ОС семьи | Пользователь открывает страницы, нажимает кнопки и запускает команды сам |

Не обещайте отправить APK на телевизор, пока у вас нет подходящих инструментов и соединения с ним. В браузере помощника и на компьютере пользователя могут быть разные файловые системы: сначала установите, где реально находится скачанный файл. Если инструмента нет, назовите конкретный недостающий шаг и дайте выполнимую инструкцию. Не сообщайте «установлено» по факту одной сборки.

**Результат этапа:** известны совместимый экран, способ установки и действия, которые помощник может выполнить сам.

## 2. Зарегистрируйте семью

1. Откройте личную ссылку `/setup/#invite=…`. Не публикуйте её в GitHub и не помещайте в общую инструкцию: это приглашение одной семье. Просмотр не расходует ссылку, успешное завершение регистрации расходует.
2. Если кабинет уже создан, используйте его `/parent/`; не создавайте вторую семью и не просите повторное приглашение для установки ТВ.
3. В мастере помогите добавить имена 1–6 детей. Спросите, хотят ли родители фотографии. Пусть укажут соответствие фото и имени. При отсутствии фотографий оставьте аватары и продолжайте.
4. Проверьте местное время. Оно определяет день, доступность отметок и периоды целей; фиксированное смещение не переключается на летнее время автоматически.
5. Вместе просмотрите задания каждого ребёнка. Пять обязательных утренних действий сохраняют свои идентификаторы. Дневные, супердела и повторяемые дела можно адаптировать. Название прогулки может содержать «30 минут», но приложение не измеряет длительность прогулки датчиками.
6. На шаге целей выберите ребёнка, добавьте еженедельную, ежемесячную или индивидуальную цель и объясните очки, шаги, результат и пропуски. Отсчёт новых личных целей начинается с сохранения. Можно начать без личных целей и добавить их позже.
7. Родители сами задают один или два шестизначных кода и подтверждают размещение данных. Новый секрет не придумывайте и не вводите вместо пользователя, если правила вашей среды требуют его самостоятельного ввода. Вход в готовый кабинет выполняется по коду: имя родителя служит подписью в журнале, отдельной пары «логин и пароль» в форме нет.
8. Завершите регистрацию только после проверки введённых сведений и согласия пользователя. Подтверждением служит экран «Ваша семья на месте» и доступный семейный журнал. Открытие мастера ещё не означает завершённую регистрацию.

Если помощник не может сам заполнить форму, говорите конкретно: «Откройте ссылку, сейчас заполним имена. Нажмите “Дальше”, когда закончите». Не отправляйте пользователя изучать исходный код.

**Результат этапа:** открыт семейный журнал после успешной регистрации; имена и время верны.

## 3. Настройте телефоны родителей

Родительская часть уже работает как веб-приложение: отдельный APK для родителя не нужен. Откройте HTTPS-адрес этой семьи с окончанием `/parent/`. Пусть второй родитель войдёт своим кодом. Не путайте этот адрес с использованной ссылкой приглашения.

Помогите сохранить значок:

- iPhone / iPad: открыть кабинет в Safari, меню «Поделиться», «На экран “Домой”», подтвердить название.
- Android: открыть кабинет в Chrome, меню браузера, «Добавить на главный экран» или «Установить приложение», если такой пункт предложен. Названия зависят от версии браузера.
- Если пункта нет, сохраните закладку: кабинет уже доступен по ссылке. Не утверждайте, что требуется магазин приложений.

Проверьте повторное открытие кабинета и объясните, что оба родителя видят одну семейную базу.

**Результат этапа:** кабинет открывается на телефонах родителей.

## 4. Получите настройки экрана

В авторизованном кабинете откройте «Подключить экран» → «Скачать настройки нашей семьи». Если у вас есть управление браузером и пользователь поручил подключить экран, **сами нажмите кнопку и получите файл**. Не просите его писать в чат «я скачаю настройки», не отправляйте его за ними к автору проекта.

Если доступного браузера нет, дайте ровно эти два нажатия и помогите выбрать скачанный ZIP в инструментах помощника. Объясните простыми словами: «Внутри уже есть данные вашей семьи и подключение телевизора. Ничего вручную в файлах заполнять не надо». Если пользователь уже вошёл в кабинете вашего браузера, повторно спрашивать код не нужно.

Скачанный ZIP содержит `config/family.json`, `sync/catalog.json`, `web/avatar-*.png` и `connection/tv.properties` (также варианты для машины и планшета). Родительских кодов в нём нет. Это приватный пакет: в нём есть доступ детского устройства. Храните его в рабочем каталоге семьи, исключённом из публичных публикаций. Не выводите содержимое `.properties` и токены в ответы или логи.

**Результат этапа:** частный ZIP получен в доступную помощнику рабочую папку.

## 5. Подготовьте приложение

Подготовьте приватную рабочую копию и выполните [технический порядок сборки](install.md#3-сборка-детского-приложения). Этот раздел одинаков для приглашённой семьи и собственного сервера. В нём описаны перенос файлов ZIP, инструменты под ОС компьютера, команда сборки и сохранение подписи.

Сборка должна использовать именно семейный `tv.properties`. APK без него показывает локальные данные и не подключает ТВ к журналу. Для приглашённой семьи не создавайте новый сервер или новые доступы устройств.

**Результат этапа:** существует проверенный семейный APK; известен его путь. Это ещё не установка на ТВ.

## 6. Подключите телевизор и установите приложение

### Домашняя сеть

Попросите подключить ТВ к домашнему Wi-Fi или Ethernet и открыть сведения о сети. Компьютер должен быть в той же доступной локальной сети. Гостевой Wi-Fi часто запрещает устройствам видеть друг друга. Не требуйте одинаковой частоты 2,4/5 ГГц: важна доступность между устройствами. IP берите с экрана самого телевизора.

### Отладка с сопряжением

На поддерживаемой модели проведите человека через включение параметров разработчика: обычно это несколько нажатий на номер сборки в «Об устройстве», затем раздел «Для разработчиков». Число нажатий и названия уточняйте для модели. Нужен доступ владельца к пульту.

Если есть «Беспроводная отладка» с кодом сопряжения, получите показанные телевизором адрес и порт. Выполните:

```sh
adb pair TV_IP:PAIR_PORT
# Введите код, показанный на телевизоре, когда его запросит adb.
adb connect TV_IP:DEBUG_PORT
adb devices -l
```

Порт сопряжения и порт подключения могут различаться и меняться. Не подставляйте 5555 в оба поля автоматически. Код используется только для разрешённого подключения к этому устройству. Поддержка сопряжения зависит от версии ТВ; современные инструкции Android описывают его для TV начиная с Android 13. [Официальная инструкция ADB](https://developer.android.com/tools/adb#connect-to-a-device-over-wi-fi).

Если модель поддерживает другой штатный вариант сетевой/USB-отладки, следуйте её официальной инструкции. Не запускайте `adb tcpip 5555` вслепую на неподключённом устройстве. Если появляется запрос разрешить отладку с компьютера, попросите владельца подтвердить его на ТВ.

### Установка и запуск

Убедитесь, что нужный телевизор отображается со статусом `device`. При нескольких устройствах выбирайте конкретный `SERIAL` из списка:

```sh
adb -s SERIAL install -r .local/apk/family-quest-tv.apk
adb -s SERIAL shell am start -n org.familyquest.starter/.MainActivity
```

`SERIAL` — фактический идентификатор из `adb devices`, а не буквальный текст. После `Success` откройте «Семейный квест» из списка приложений или командой запуска. Проверьте видимый экран и управление пультом. Не устанавливайте файл на первое случайное Android-устройство.

Если ADB недоступен, предложите разрешённую для этой модели установку готового APK через USB-накопитель или доверенный способ передачи файлов. Человек выбирает файл и подтверждает установку на самом телевизоре. Временное разрешение установки относится к выбранному приложению-источнику. Не обходите ограничения закрытой системы. Объясняйте, где взять уже собранный файл, а не предлагайте искать произвольный APK в интернете.

Не открывайте порты отладки в интернет. После установки обсудите отключение отладки, если она больше не нужна: работа трекера использует HTTPS, а не ADB. Если компьютер помощника находится удалённо и не видит домашнюю сеть, честно выберите передачу готового файла или локальные действия человека.

**Результат этапа:** приложение действительно запущено на выбранном телевизоре.

### Дополнительный экран в машине

Если семья хочет автомобильный экран, выполните [установку в машину](car-install.md) с `car.properties` и `mode=car`. Это тот же журнал, а не новая семья. Проверьте модель, разрешённую установку APK, касания и реальный обмен через Wi-Fi/LTE на стоянке. Не считайте наличие SIM доступом к ADB. Затем включите машину в проверку этапа 7.

## 7. Проверьте весь путь

1. На телевизоре видны имена семьи и выбранные фотографии/аватары. Видимая синхронизация не сообщает ошибку.
2. Стрелками и OK откройте ребёнка, переключите категории, дойдите до последнего задания и вернитесь кнопкой «Назад». Текст и фокус читаются с дивана.
3. Выберите с родителем действительно выполненное сегодня дело, отметьте его на ТВ и найдите отметку в родительском кабинете. Не заполняйте детям реальные достижения ради теста без согласования.
4. Через «Задания дня» добавьте согласованное пробное дело. Дождитесь его на детском экране. Исправления делает родитель; проверьте их синхронизацию. После отправки читайте фактическое состояние, а не обещайте фиксированное число секунд обновления.
5. Проверьте второго родителя, цель с частичным прогрессом и копилку, если в них уже есть реальные данные. Отсутствие заработка в новой семье нормально.

Скажите, что проверено физически, а что только собрано/показано в браузере. В конце оставьте семье адрес кабинета, путь к её APK и подписи, короткую памятку пользования. Не публикуйте семейный архив и личное приглашение вместе с отчётом.

**Результат этапа:** подтверждён обмен в обе стороны и управление пультом.

## 8. Научите семью пользоваться трекером

Покажите действия по [памятке родителей](family-guide.md), в том же порядке, что они будут нужны семье:

| Просьба | Действие в кабинете |
| --- | --- |
| «Добавь всем прогулку больше 30 минут ежедневно» | «Настройки дел» → название → «После школы» → нужные дети → «Добавить дело» |
| «Собирать модель можно несколько раз» | Там же категория «Повторяемые дела», ставка и дети |
| «Сегодня полить цветы» | «Задания дня» → текст → «Добавить на сегодня» |
| «Месячную цель Алексу» | «Цели на неделю и месяц» → «Настроить цели» → Алекс → «＋ Ежемесячная цель» → условия → «Сохранить цели» |
| «Исправь ошибочную галочку» | «Проверка дел» → нужный ребёнок и дело → снять отметку |
| «Выдали часть накопленного» | «Списать из копилки» → фактическая сумма и пояснение |

С управлением экраном и браузером помощник может выполнять разрешённые действия в кабинете после входа. Пользователь может войти самостоятельно; передавать код текстом необязательно. В обычном чате без доступа к кабинету давайте точные нажатия для ручного выполнения.

Не создавайте нового бота или MCP ради этих операций. Для существующего HTTP-доступа есть [отдельный справочник](parent-api.md). Ограничения целей, ставок, расписаний и управления телефоном сверяйте с памяткой родителей, а не с обсуждениями будущих функций.

**Завершение:** оставьте адрес кабинета, путь к APK/подписи и ссылку на памятку. Назовите подтверждённые устройства и конкретные оставшиеся шаги, если они есть. После установки компьютер для ежедневной синхронизации не нужен.
