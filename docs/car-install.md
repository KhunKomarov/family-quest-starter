# Установка трекера в машину

Это дополнительный детский экран той же семьи: галочки, цели и копилка общие с телевизором и родительскими телефонами. Регистрировать вторую семью не нужно. Выполняйте подключение и проверку на стоянке.

## 1. Проверьте совместимость

Уточните модель мультимедийной системы, Android и разрешённый изготовителем способ установки APK. Нужен Android 9+ с возможностью установки сторонних приложений. Android Auto и CarPlay не запускают этот APK. У закрытой системы не обещайте установку: используйте поддерживаемый Android-планшет. Подключение не требует менять автомобильные датчики или настройки управления машиной.

## 2. Получите настройки своей семьи

В существующем родительском кабинете: «Подключить экран» → «Скачать настройки нашей семьи». Сохраните частный ZIP и перенесите его файлы по [порядку сборки](install.md#3-сборка-детского-приложения). Для автомобиля выберите `connection/car.properties`, сохранённый как `.local/connection/car.properties`. В нём `mode=car` и собственный доступ этого экрана. Не используйте вместо него телевизионные настройки и не печатайте токен в чат.

## 3. Соберите автомобильный APK

Используйте ту же семейную рабочую копию с именами, каталогом и аватарами; сохраните ключ подписи для обновлений. После подготовки SDK/JDK по инструкции установки:

```sh
python3 scripts/configure.py --check
bash scripts/build-android.sh .local/connection/car.properties .local/apk/family-quest-car.apk
```

Проверьте успешное окончание и наличие APK. В режиме `car` включены касания, крупные кнопки и экранный возврат. Это ещё не подтверждение установки на автомобиль.

## 4. Установите разрешённым способом

Уточните доступный путь у конкретной модели. При установке с USB человек открывает готовый APK в файловом менеджере экрана и подтверждает установку. Если модель поддерживает ADB, компьютер и машина подключены к доступной сети, подтвердите отладку на экране и найдите именно автомобиль в `adb devices -l`.

```sh
adb devices -l
adb -s SERIAL install -r .local/apk/family-quest-car.apk
adb -s SERIAL shell am start -n org.familyquest.starter/.MainActivity
```

Вместо `SERIAL` укажите фактический идентификатор машины. Не устанавливайте файл на случайный телефон из списка. Подтверждённое `Success` проверьте запуском приложения. Сохраните прежний ключ и пакет при обновлениях, чтобы не терять локальную очередь. Не открывайте ADB-порт в интернет: наличие SIM не означает доступ для удалённой установки.

## 5. Проверьте касания и общий журнал

1. Имена, аватары и дела совпадают с родительским кабинетом.
2. Пальцем открываются все профили, категории и последние строки; список прокручивается, кнопка возврата работает. Для короткого широкого экрана сверяйтесь с [памяткой экранов](screens.md).
3. С согласия родителя отметьте действительно выполненное дело и найдите его в кабинете и на телевизоре. Через кабинет проверьте обратное обновление. Не заполняйте достижения ради демонстрации.
4. При доступном интернете через SIM / LTE или точку доступа отметки передаются до приезда домой. На стоянке проверьте обмен по этому каналу отдельно от домашнего Wi-Fi.
5. Без интернета галочки сохраняются в локальной очереди. Они появятся на других экранах после возвращения связи и обмена приложения с сервером. Домашний Wi-Fi подходит для такого отложенного обмена.

**Готово:** зафиксированы модель, версия установленного APK, проверенное управление и фактический канал обмена. Компьютер для обычного использования не нужен. Если доступна только сборка, честно укажите, что установка или проверка ещё впереди.
