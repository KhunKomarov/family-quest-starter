# Самостоятельная установка и сборка

**Есть личное приглашение?** Идите по [основному маршруту](agent-guide.md): этапы 1–2 ниже вам не нужны. Раздел 3 служит общим техническим справочником сборки APK.

## 1. Подготовьте собственную конфигурацию

Создайте частную рабочую копию проекта. По [форматам настройки](customize.md) задайте профили, время, аватары и начальный каталог; затем выполните `python3 scripts/configure.py`. Состав каталога должен соответствовать числу профилей. Сохраните стабильный порядок детей после первого запуска.

## 2. Запустите собственный сервер

Выполните [последовательную настройку Ubuntu, службы и HTTPS](hosting.md). Там же указан рабочий пример мощности сервера. Откройте `/parent/` по своему HTTPS-адресу и проверьте вход родителей. Данные устройств и коды создаются один раз; при обновлениях их не пересоздают.

Дальше продолжайте с [этапа 3 основного маршрута](agent-guide.md#3-настройте-телефоны-родителей): сохраните кабинет на телефонах и получите параметры детского экрана. Для собственной установки файлы `.properties` берутся из её закрытого каталога данных. Для приглашённой семьи их содержит скачанный ZIP.

## 3. Сборка детского приложения

1. Возьмите актуальные исходники из `https://github.com/KhunKomarov/family-quest-starter` в приватную рабочую копию. Для обновления существующей установки используйте её сохранённую копию и ключ подписи. Не заменяйте ключ при каждом обновлении.
2. Проверьте имена файлов ZIP перед распаковкой: только относительные пути без выхода из рабочего каталога. Скопируйте конфигурацию, каталог и аватары в соответствующие пути рабочей копии. Файлы из `connection/` сохраните в `.local/connection/` этой копии, чтобы использовать команду ниже. Для собственного сервера без ZIP перенесите туда его `.properties`. Не подменяйте их демонстрационными данными.
3. На компьютере сборки нужны Python 3.9+, Bash, `zip`, JDK 17, Android SDK Platform 35 и Build Tools 35.0.0. Для установки по ADB нужны Android Platform Tools. Сначала проверьте уже установленные инструменты. Android Studio может предоставить SDK через SDK Manager. Загружайте инструменты из официальных источников и соблюдайте правила согласия вашей среды на установку и лицензионные условия.
4. Подготовьте команды под фактическую ОС. `scripts/build-android.sh` — Bash-скрипт. На Windows используйте проверенную среду Bash/Linux, а не вставляйте Bash-команды в PowerShell как будто они одинаковы. Если сборка в WSL, отдельно проверьте доступ из среды установки к ТВ и пути к APK. Локальный Windows `adb` и WSL — разные окружения.
5. Укажите `JAVA_HOME` и `ANDROID_HOME` / `ANDROID_SDK_ROOT` по реальным путям. Скрипт также принимает `FAMILY_BUILD_TOOLS` и `FAMILY_ANDROID_JAR` для нестандартного расположения. Не копируйте чужие абсолютные пути.
6. Из корня частной копии выполните:

```sh
python3 scripts/configure.py
python3 scripts/configure.py --check
# Подставьте реальный путь к tv.properties из скачанного ZIP.
bash scripts/build-android.sh .local/connection/tv.properties .local/apk/family-quest-tv.apk
```

Сохраните `.local/signing.p12` и `.local/signing.pass` у семьи для будущих обновлений. Убедитесь, что использован именно файл `tv.properties`: сборка без него — локальный просмотр, она не подключит экран к семейному серверу. Проверьте результат скрипта и существование APK; при ошибке исправьте сборку до передачи файла пользователю.

Сборка не требует изменения кода под каждую семью. Для этого пути не запускайте новый сервер, не вызывайте `init-instance.py` с новыми доступами, не меняйте серверные ключи и не просите у семьи SSH или доступ к DigitalOcean.

## 4. Подключение экрана

Выполните [этап 6 основного маршрута](agent-guide.md#6-подключите-телевизор-и-установите-приложение): сеть, отладка, установка и запуск. Затем обязательна [проверка обмена](agent-guide.md#7-проверьте-весь-путь).

Для планшета используйте `tablet.properties` с `mode=touch`, для совместимого автомобиля — `car.properties`. Сверьте [памятку экранов](screens.md). Автомобиль подключают на стоянке. Android Auto / CarPlay не являются средой установки этого APK.

## Проверки проекта

Для изменения кода, а не вместо проверки установки на устройстве:

```sh
python3 scripts/configure.py --check
# Для тестов регистрации нужен Pillow.
python3 -m unittest discover -s tests
npm install --no-save playwright
npx playwright install chromium
node --test tests/*.cjs
```

С установленным Chrome можно задать `FAMILY_TEST_CHROME` с путём к исполняемому файлу.

## Локальная проверка

Необязательный просмотр с отдельным тестовым журналом. Нужен Python 3.9+; эти команды не создают синхронизацию с действующей семьёй:

```sh
python3 scripts/init-instance.py --directory .local/preview
python3 sync/server.py --preview --database .local/preview/journal.sqlite3 \
  --tokens .local/preview/devices.json --parents .local/preview/parents.json
```

Откройте `http://127.0.0.1:8765/parent/` и используйте тестовый код из частного `parents.json`. Для одного только детского демо достаточно команды просмотра из [README](../README.md).

Для подключения автомобиля выполните отдельную [пошаговую установку в машину](car-install.md).
