# Инструкция для агента

Помоги семье получить работающие родительский кабинет и телевизор, затем научи пользоваться трекером. Начни с [основного руководства для нейросети](docs/agent-guide.md), [памятки семье](docs/family-guide.md), [README](README.md) и [вводных](docs/intake.md). Уточняй только то, без чего невозможно продолжить. Если передано личное приглашение или адрес готовой семьи, сервер уже есть: сразу веди по приглашённому сценарию, не спрашивай заново, где арендовать сервер.

Говори простыми словами, по одному небольшому шагу. Сам выполняй разрешённые действия, для которых есть инструменты. С браузером и терминалом сам скачай настройки из авторизованного кабинета, подготовь APK и установи его на доступный телевизор. Не заставляй родителя заранее обещать «скачать настройки» и разбираться в файлах. При отсутствии инструментов честно дай конкретные действия. Сам вход в кабинет не означает завершённую установку.

1. Сверь список устройств, версии Android, доступ к локальной сети и нужен ли доступ вне дома. Выбери режим пульта или касания по [инструкции адаптации экранов](docs/screens.md). Если модель не поддерживает установку, предложи поддерживаемый планшет или ТВ-приставку.
2. При настройке спроси имена или псевдонимы детей для профилей и попроси их фотографии, уточнив, какое фото к какому ребёнку относится. Если фотографий нет или семья не хочет их использовать, предложи оставить стандартные аватары; это не должно задерживать установку. Для приглашённой семьи помоги заполнить мастер по личной ссылке: он поддерживает 1–6 детей, фотографии, дела и цель, сохраняет их прямо в отдельный журнал. Родительские коды пользователь вводит сам. Для собственной установки меняй имена, время и цель в `config/family.json`, согласуй число меню с числом детей и выполни `python3 scripts/configure.py`. Сохраняй стабильный порядок профилей после первого запуска.
3. Уточни ежедневные и повторяемые задания до и после школы, суперзадания и один пример разового дела. Используй `sync/catalog.json` только для новой базы. После запуска разовые и постоянные дела добавляются через родительскую панель. Уточни еженедельные, ежемесячные и индивидуальные цели отдельно для каждого ребёнка, сроки, шаги и число пропусков. Их можно менять на отдельной странице «Цели детей». Смотри [настройку](docs/customize.md).
4. Если сценарий ещё не известен, уточни, есть ли приглашение или нужен свой сервер. Для приглашённой семьи следуй [полному маршруту](docs/agent-guide.md) и [регистрации](docs/hosted.md): нужна личная ссылка `/setup/#invite=…`; после регистрации сам скачай частные настройки в разделе «Подключить экран», если умеешь управлять браузером. Без этого инструмента объясни два нужных нажатия. Не проси передавать файлы через автора, не предлагай аренду VPS и не запрашивай SSH-доступ или ключи администратора. Публичная ссылка на код не является приглашением к чужой семье. Для собственной установки подбери [сервер](docs/hosting.md) и следуй [установке](docs/install.md). Сначала проверь вход родителей и один детский экран, затем остальные.
5. Создавай новые секреты в приватном каталоге на компьютере владельца. Храни APK с токеном, подпись, рабочую базу, фото и данные семьи в её закрытой установке. В репозитории и демонстрациях используй вымышленные данные. Для семейного журнала сохраняй его резервную копию перед обновлением.
6. Проверь, что задание дня появляется на детском экране, отметка появляется у родителя, а после исправления обновляются оба устройства. Проверь кнопки пульта или касание, часы семьи, частичную ячейку и перенос цели. Скажи владельцу, какие устройства проверены физически.

После установки покажи «Настройки дел», «Цели детей», «Проверку дел», котиков с пояснениями, копилку и частичное списание. Объясни добавление дела нескольким детям. Помощник с доступом к браузеру может после входа работать в этих формах по команде родителя; отдельный MCP для браузерного управления не нужен. В обычном текстовом чате автоматического доступа нет. Не обещай готовые API-ключи для нейросети, автоматический Family Link, расписание дел по дням недели, общий переключатель назначения целей всем детям или привязку цели только к конкретному упражнению: эти возможности не реализованы. Новая разработка API/бота не является условием установки.

Перед завершением выполни `python3 scripts/configure.py --check`, `python3 -m unittest discover -s tests` и проверки JavaScript из [инструкции установки](docs/install.md). Отдельно отметь, если модель устройства или сервер ещё недоступны для установки.
